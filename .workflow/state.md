## Phases

```
IDEA → DISCOVERY → SPECIFICATION → DESIGN → PLANNING
     → IMPLEMENTATION → TESTING → REVIEW → SHIPPING → DOCUMENTATION
```

| Phase | Skill | Entry condition |
|---|---|---|
| DISCOVERY | `/grill-me` | An idea exists and is not yet understood |
| SPECIFICATION | `/to-spec` | `docs/discovery.md` exists, open questions resolved |
| DESIGN | `/ui-design` | `docs/spec.md` describes user-facing behavior |
| PLANNING | `/to-tickets` | `docs/spec.md` exists |
| IMPLEMENTATION | `/implement` | A ticket in `tickets/` is selected |
| TESTING | `/test` | Code is written and needs verification |
| REVIEW | `/review` | Tests pass |
| DEBUGGING | `/debug` | Something is broken |
| SHIPPING | `/ship` | No BLOCKER or IMPORTANT findings remain |
| DOCUMENTATION | `/document` | Code and spec have diverged, or after a release |
